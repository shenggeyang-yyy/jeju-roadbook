🛍️ 西归浦每日偶来市场｜서귀포매일올레시장

推荐度 ★★★★★1–2.5h雨天★★★★★有顶棚

它不是单纯的“游客夜市”，白天还是一个真正工作的传统市场；傍晚开始熟食和游客小吃的存在感更强。官方资料显示市场约 620m 长，夏季约 07:00–21:00、冬季约 07:00–20:00，全年营业，但具体摊位时间不同。

这里到底有什么？

  • 🍊 济州柑橘、汉拿峰、果汁和柑橘伴手礼
  • 🍡 오메기떡（济州传统年糕）、빙떡（荞麦萝卜卷）
  • 🐟 银带鱼、鲭鱼、옥돔（玉鲷）、海螺等海产
  • 🐖 黑猪肉铁板/串烧
  • 🐙 烤鱿鱼、章鱼、炸物
  • 🍗 蒜香炸鸡 / 마농치킨
  • 🍣 生鱼片、外带寿司、紫菜包饭
  • 🎁 济州石爷周边、柑橘周边、零食礼盒

怎么逛更舒服？

  1. 第一圈先看。 同类摊位很多，先比较价格、分量、排队。
  2. 第二圈开始吃。 三个人每样买一份分着吃，能多试几样。
  3. 最后买水果/伴手礼。 不然一路提着很累。
市场里“排队最长”不等于“最好吃”。近期实访攻略也建议看实际分量、展示价格和储存条件，不要只跟队伍走。

🎨 李仲燮街｜이중섭거리

30–60min顺路型

不需要把它当“大景点”。它的价值是和市场、老城、李仲燮相关空间天然串起来，适合走完路之后慢慢晃。

🌉 新缘桥｜새연교 + 鸟岛｜새섬

30–60min傍晚/夜景

💧 天地渊瀑布｜천지연폭포

老城临时加项。它和市场、新缘桥组合比“专门跨岛看一个瀑布”合理得多。

🥾 偶来6号线｜제주올레 6코스

这趟旅行里唯一明确想“完整走完”的长距离路线。

约10.1km约3–4h全程步行

路线：쇠소깍 → 하효쇠소깍해변 → 제지기오름 → 보목포구 → 구두미포구 → 소정방폭포 → 이중섭거리 → 서귀포매일올레시장 → 제주올레여행자센터

쇠소깍

河口、黑色火山岩和海水颜色很有辨识度；适合正式开始走之前留20分钟。

제지기오름

体力允许再认真爬。目标不是打卡登顶，而是给海岸线增加一点地形变化。

보목포구

比“大景区”更像普通济州海边生活，适合慢走、看港口。

소정방폭포

路上的小瀑布，适合顺路停，不需要单独排半天。

🌋 济州东部 × 牛岛｜우도

10/15已有Grand Hyatt东线牛岛团：城山日出峰 → 牛岛 → 涉地可支 → 月汀里 → 咸德。当天以酒店实际安排为准。

城山日出峰｜성산일출봉

地图平台结果：4.6 / 5（2104条）

水成火山凝灰锥，是东部最有辨识度的地貌。酒店团如果给足时间，值得登上去；时间紧就看海岸和火山锥。

牛岛｜우도

地图平台结果：4.6 / 5（447条）

轮渡约15分钟。适合海岸、骑行、慢节奏。船班受天气影响，返程时间当天确认。

月汀里｜월정리

地图平台结果：4.3 / 5（168条）

海滩 + 咖啡街的组合比“只打卡一张海”更合理。

咸德｜함덕서우봉해변

地图平台结果：4.5 / 5（149条）

白沙、浅色海水、旁边有犀牛峰（서우봉）景观。适合结束东线时散步。

🥜 牛岛到底吃什么？

牛岛最典型的是 땅콩 아이스크림｜花生冰淇淋。官方 Visit Jeju 也专门做过牛岛花生冰淇淋专题。把它当“当地特色甜点”即可，不需要为了某一家排长队。

近期攻略常见价格约 ₩3,000–4,000。酒店团停留时间有限时，优先海岸和你真正想看的景色，冰淇淋顺路买。
